## 🎯 Sobre o Projeto

O **MUSE Hair Atelier** é um UI Concept desenvolvido para compor meu portfólio de desenvolvimento front-end. O projeto apresenta a proposta de um salão de beleza premium com uma experiência digital completa, reunindo uma landing page moderna, um fluxo de agendamento intuitivo e um dashboard administrativo para gerenciamento dos atendimentos.

Embora desenvolvido utilizando HTML, CSS e JavaScript, este conceito pode servir como base para aplicações reais utilizando React, TypeScript, Next.js, APIs, autenticação, banco de dados e integrações com serviços de pagamento e notificações.

## ⚡ Funcionalidades

### 🏠 Landing Page

- Hero section premium
- Apresentação dos serviços
- Equipe de profissionais
- Galeria visual
- Depoimentos de clientes
- Informações de contato
- Navegação suave entre seções

### 📅 Agendamento Online

- Fluxo em múltiplas etapas
- Seleção de serviço
- Escolha do profissional
- Seleção de data
- Escolha de horário
- Confirmação do agendamento
- Interface intuitiva e responsiva

### 📊 Dashboard Administrativo

- Cards com indicadores principais
- Total de agendamentos
- Clientes cadastrados
- Faturamento estimado
- Agendamentos do dia
- Histórico de atendimentos
- Filtros por status e data
- Atualização de status dos agendamentos
- Notificações em tempo real (Toast)
- Tabelas dinâmicas

## 🎨 Destaques do Design

- **Visual Premium** inspirado em salões de alto padrão
- **Glassmorphism** em elementos da interface
- **Tipografia Elegante** com combinação serif + sans-serif
- **Microinterações** e animações suaves
- **Paleta sofisticada** com tons neutros e dourados
- **Dashboard clean** focado em usabilidade

## 💼 Sobre este Case

Este projeto faz parte da coleção de **UI Concepts** desenvolvidos para meu portfólio. O objetivo é demonstrar minha abordagem na criação de interfaces modernas, experiências de usuário intuitivas e sistemas administrativos voltados para negócios do setor de beleza e estética.
